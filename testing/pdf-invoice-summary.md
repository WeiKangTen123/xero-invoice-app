## Proposed Parser Logic for ACCPAY (Bills)

```
1.  PDF arrives as email attachment
2.  Extract text with pdf-parse
3.  Detect currency → SGD if PayNow/SGD keyword; USD if USD/$
4.  Extract vendor name → "Name" block / letterhead / first company line
5.  Extract invoice number → "Invoice #" / "INV-" → fallback: filename prefix
6.  Extract invoice date → "DATE", "Date of Issue", service date
7.  Extract due date → "Due Date:" → fallback: invoice date + 30 days
8.  Extract line items → match layout pattern per vendor format
      Thitipat: "Project :" block
      Branworks: lines between DESCRIPTIONAMOUNT and Total
      Others: single amount line
9.  Tax: default ZERO_TAX_RATE (CAN030 = Exempt Sales 0%)
10. POST to Xero as ACCPAY (Bill) Draft
```
